# مثلث برمودا: الأسطورة والحقيقة — حزمة إنتاج فيديو يوتيوب (15 دقيقة)

حزمة إنتاج كاملة لوثائقي يوتيوب بالعربية الفصحى عن مثلث برمودا، بنبرة متوازنة
(سرد الحوادث الغامضة ثم تفكيكها بالأرقام والتفسير العلمي).

## محتويات الحزمة
| المسار | الوصف |
|---|---|
| `narration.md` | النص المسموع النهائي: 11 كتلة سردية (افتتاحية تشويقية، تعريف المثلث، نشأة الأسطورة، 6 ملفات حوادث، انقلاب لاري كوشي، موقف المؤسسات، التفسير العلمي، إل فارو 2015، الخاتمة) |
| `build/make_titles.py` | رسم العناصر العربية (بطاقة العنوان، أشرطة الفصول، خريطة المثلث، العلامة المائية، بطاقة الختام) باستخدام PIL + arabic-reshaper + python-bidi |
| `build/make_music.py` | موسيقى تصويرية إجرائية (درُون منخفض + ضجيج محيط + ضربات Sub عند الفصول) |
| `build/make_audio.py` | معالجة التعليق الصوتي: قصّ الصمت، ضبط السرعة للوصول إلى 15:00، بناء ماستر الصوت والتوقيتات |
| `build/assemble.py` | المونتاج: لقطات Ken Burns من الخلفيات + دمج العناصر + مزج الصوت + تصدير MP4 وSRT |
| `fonts/` | خطوط عربية حرة (Vazir، Sahel، Parastoo — رخص SIL OFL) |
| `images/` | خلفيات سينمائية مولّدة (خارج Git بسبب الحجم) |
| `audio/` | مقاطع التعليق الصوتي (خارج Git) |
| `output/` | الفيديو النهائي `bermuda_triangle_15min.mp4` + الترجمة `bermuda_triangle_ar.srt` (خارج Git) |

## إعادة البناء
```bash
pip install pillow arabic-reshaper python-bidi numpy imageio-ffmpeg
cd bermuda-video/build
python3 make_titles.py          # العناصر الرسومية
python3 make_audio.py 1.0       # قياس المدة الخام، ثم إعادة التشغيل بمعامل atempo المحسوب
python3 assemble.py             # المونتاج والتصدير
```

## ملاحظات إنتاجية
- معدل النطق المقاس للصوت العربي: ~9.5 حرف/ثانية؛ يُضبط معامل `atempo` آلياً ليبلغ
  مجموع السرد ~884 ثانية فتقع مدة الفيديو النهائية عند 15:00 (±10 ثوانٍ).
- الوسائط الثقيلة (صور/صوت/فيديو) مستثناة من Git عبر `.gitignore` وتُعاد توليدها محلياً.
- المصادر Fact-checked: تحقيق لاري كوشي 1975، موقف Lloyd's وخفر السواحل الأمريكي،
  دراسة WWF 2013 لأخطر المسطحات المائية، وتحقيقات حادثة إل فارو (NTSB).
